OSD text

The overlays are burnt into the video, so the preview shows them as the stream does. scale 0 = auto (2 at 720p). Positions: 0 or more from the left/top edge, negative from the right/bottom edge. Text is ASCII only; longer lines and extra rows are cut off.

Image osd.imagefile · a raw BGRA picture, written from a PNG by osd-feed

Even sizes only; the file must be exactly width × height × 4 bytes, so osd-feed converts the PNG to this size (slots.imagefile.png in osd-feed.json, docs/osd-feed.md). Needs width × height × 4 bytes of OSD pool on top of the text overlays (1280 × 720 = 3.6 MB: osd_pool_size 8192).

Apply / save
Only allocated when prudynt starts. Changing it makes osd-config write /etc/prudynt.json and restart prudynt (the stream drops for a few seconds). Takes effect through "Save" only.

"Apply now" sends the settings to the running prudynt only (prudyntctl). "Save" writes /mnt/mmcblk0p1/prudynt-osd.json (…); osd-config picks it up within 5 s, and again after every prudynt restart. Nothing is written to flash except osd_pool_size. Other keys already in the file are kept.
